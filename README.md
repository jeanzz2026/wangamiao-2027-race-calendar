# 王阿喵 · 2027 参赛训练计划

一个纯静态网页应用，用于管理王阿喵的 **2027 年比赛训练计划、基础训练库与打卡记录**，部署在 GitHub Pages。

🌐 在线地址：https://jeanzz2026.github.io/wangamiao-2027-race-calendar/

---

## 功能介绍

### 1. 赛事日历与训练计划排布
- 在日历上排布 2027 年目标赛事（参赛日期、地点、类型等）。
- 在任意日期添加训练内容，形成可视化的全年训练计划。

### 2. 基础训练库
- 内置常用训练动作，并按类型区分：**路跑 / 越野 / 通用**。
- 可新增、编辑、删除训练动作，维护自己的训练库。
- 从训练库**一键「快速添加」**到某天计划；添加后可单独编辑该次训练的时长 / 说明，**不影响训练库原始内容**。

### 3. 打卡记录
- 独立的「打卡」模式，对计划中的训练进行打卡。
- 打卡按钮位于每张训练卡片**最底部**；点击后变为「已打卡」高亮状态（采用主题强调色背景 + 白字／深字）。
- 已打卡状态随训练计划一起保存与同步。

### 4. ITRA 数据面板
- 展示 **Performance Index**（当前 445）、等级（Intermediate 3）。
- 展示最佳排名、总训练距离等统计信息。
- 数据来自 `itra_data.json`，可定期抓取更新。

### 5. 配色主题
- 提供两套主题：**狗狗黑**（默认，强调色柠檬黄）/ **喵喵粉**（强调色粉红）。
- 切换即时生效，并记忆到本机，下次打开保持。

### 6. 数据持久化与同步
- **本机优先**：所有改动先写入浏览器 `localStorage`（key `wamiao_state_v2`），刷新页面或重新部署都不会丢失。
- **跨设备同步**：连接 GitHub 后，改动经你本机的 PAT 自动推送到仓库 `state.json`，多设备共享。
- **网络容错**：若遇网络异常导致云端同步失败，本机数据不受影响；网络恢复后再次编辑或刷新即可自动补同步。

### 7. 其他实用能力
- **撤销上一步** / **恢复初始训练库**。
- 分类筛选（**全部 / 路跑 / 越野 / 通用**）——同时筛选训练库列表与训练计划日历。
- **手机端响应式布局**：训练计划与打卡记录在移动端均按「左栏统计 / 日历在下」的方式展示，工具栏按钮（清空计划、撤销上一步）在窄屏下自动换行可见。

## 使用

1. 打开上面的在线地址。
2. 点击「连接 GitHub 后编辑」。
3. 粘贴你自己的 **GitHub Fine-grained PAT**（仅限本仓库 `Contents: Read and write` 权限），连接并登录。
4. 登录后任何编辑都会自动保存到本机并同步到仓库，多设备共享。

> token 只保存在你本机浏览器（`localStorage`），不进源码、不写云端、不暴露给任何访客。

---

## 安全模型

- 站点为公开 Pages，数据任何人都可见（仅查看）。
- 编辑需「连接 GitHub」：用你自己的 PAT 登录，源码中**不含任何共享写凭据**。
- 加载时公开拉取 `state.json`，无需 token；保存时经你本机 token 写回仓库。

## 部署（站主）

本仓库为站点发布仓库，存放构建产物、运行数据与文档。源码在本地维护，通过部署脚本发布。

部署走 `deploy_rest.py` 的 GitHub Contents API：

1. 将 GitHub token 放入 `.deploy_token`（参考 `.deploy_token.example`，已被 `.gitignore` 忽略，绝不入库）。
2. 本地构建：`node node_modules/vite/bin/vite.js build`。
3. 部署：`python deploy_rest.py`。

> 每个正式版本都会打 Git Tag 并创建 GitHub Release（见下），可随时回退到对应版本的文件或重新部署该版本。
