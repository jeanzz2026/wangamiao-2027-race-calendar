# Takeaway 图片保存（v1.2.0）

选择图片、粘贴截图文件或拖入图片文件后，浏览器先压缩并显示本机预览。支持 JPEG、PNG、WebP、GIF；GIF 保存静态画面，透明背景转白色。原图不超过 25 MB，最长边缩小至 1600px，压缩结果不超过 1 MB。

点击保存后，先上传独立文件至 `uploads/takeaway/<SHA-256>.jpg`，再保存评论中的固定 Git 提交图片 URL。重新编辑文字无需再次上传图片。相同压缩内容复用已有文件；不同内容不会覆盖同名文件。

图片上传失败或读取验证失败时，不发布本次云端评论。本机完整状态与图片编辑草稿保留在 IndexedDB，恢复网络/权限后可用“上传到云端”重试。再次打开同一记录时可以恢复未完成的图片草稿。

## 数据保护

- 仓库公开：图片与评论链接均公开，不要上传隐私照片。上传前预览旁会提醒。
- 浏览器压缩后只上传画面，不上传原图文件；保留历史内嵌图片，本次不自动迁移。
- 代码发布不可覆盖用户 state.json 和 uploads 文件。上传目录不是构建产物，不应清理。
- 删除评论不会自动删除图片，避免其他记录失去同一图片。删除仓库文件也不能保证删除 Git 历史中的公开副本。
- 上传成功但状态保存失败时，文件可能已存在。重试会复用它，不重复上传。

## 维护入口

压缩与独立上传在 `src/lib/image-uploads.js`；串行请求在 `src/lib/cloud-sync.js`；本机草稿在 `src/lib/local-state.js`。目前只有新加入且标记为待上传的图片进入独立上传链路，历史内嵌图片继续兼容显示。
